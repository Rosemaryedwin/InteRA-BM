# InteRA-BM

## An Explainable Multimodal Clinical–Microbiome Framework for Rheumatoid Arthritis Prediction and Biomarker Prioritization

### Overview

InteRA-BM is an integrated machine-learning framework developed to investigate the predictive value of clinical and gut microbiome features for rheumatoid arthritis (RA) classification.

The framework combines clinical and microbiome data through preprocessing, hybrid feature selection, calibrated Random Forest modelling, nested cross-validation, and SHAP-based interpretation.

### Workflow

1. Clinical and microbiome data preprocessing
2. Multimodal feature integration
3. ExtraTrees-based feature ranking
4. Boruta-based feature selection
5. Calibrated Random Forest classification
6. Nested cross-validation and model evaluation
7. SHAP-based model interpretation
8. Independent cohort evaluation

### Repository Contents

This repository contains the scripts, notebooks, and documentation associated with the InteRA-BM framework.

### Data Availability

The datasets used in this study are publicly available through their respective original publications and repositories. No participant-level data are redistributed through this repository.
